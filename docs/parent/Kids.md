# Parent · Kids

Manage every child's hero profile — create heroes, set up their logins, choose
avatars, and review their stats. Built as a mobile drill‑down: **List → Child
Detail → focused editors**, plus a **Create Hero wizard**.

## Kids list (main screen)
- **Search** kids by name.
- **Filter tabs:** All · Active (has a login) · No login.
- **Family summary chips:** number of kids and total Family XP.
- **Compact child rows:** avatar, name, XP, level · hero type · age. The top
  scorer shows a crown.
- **+ button (FAB):** start the Create Hero wizard.

## Child detail
Opens full‑screen with a hero header (avatar, name, total XP) and a stat strip:
**Level · Age · Member Since.** Below is an action list:

- **Edit Profile** — change hero name and age (age selects which mini‑games
  appear in the child's Game Zone).
- **Avatar & Theme** — pick one of four hero types (Robot, Princess, Ninja,
  Animal) or upload a custom photo avatar.
- **Security & Login** — set/update the child's **username** and **4‑digit PIN**
  so they can log in independently.
- **Statistics** — Total XP, reward points, current level and current XP; link
  to full reports.
- **Rewards** — jumps to the [Rewards](./Rewards.md) section.
- **Delete Hero** — permanently removes the child and all their data
  (confirmation required).

## Create Hero wizard
A three‑step, one‑screen‑per‑step flow:
1. **Basic Info** — hero name and age.
2. **Avatar** — choose a hero type or upload a custom avatar.
3. **Review** — confirm and create.

## How child login works
- Children never use an email. They sign in with **Family Code + Username +
  4‑digit PIN**.
- Parents can set these manually (Security & Login) or use **Generate Login** on
  the dashboard to auto‑create them.
