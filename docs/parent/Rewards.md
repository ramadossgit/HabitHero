# Parent · Rewards

Create the rewards kids can redeem with the reward points they earn, then
approve redemptions and hand out bonuses. The section is split into two focused
tabs: **Rewards** (manage) and **Approvals**.

## Rewards tab (manage)
- **Per‑child rewards** — a child selector chip row lets you choose whose
  rewards you're managing (when there is more than one child).
- **Reward rows:** icon, name, description and XP cost, with edit and delete
  actions.
- **+ button (FAB):** create a new reward.

### Create / Edit reward (mobile screen)
- **Reward name** — a combobox: tap a suggestion chip (Ice Cream, Game Time,
  Screen Time, Movie Night, …) **or type your own** custom reward.
- **Description** (optional).
- **XP Cost** — a free numeric entry (type any value), not a fixed dropdown.
- **Active** toggle — controls whether the reward is visible to the child.

## Approvals tab
- **Reward claims** — when a child redeems a reward, it appears here; tap
  **Approve** (then hand over the reward — the child confirms with "Got it!").
- **Give bonus points** — quick **+10 / +25 / +50** buttons to reward good
  behavior instantly.
- **Recent activity** — the latest reward point transactions.
- **Game Purchase Requests** — mini‑games a child wants to buy with reward
  points: **Approve** unlocks the game; **Decline** refunds the points (with an
  optional note to the child).

## Availability by mode

| Capability | Free Trial | Subscription |
|---|---|---|
| Create / edit / delete rewards (custom name, custom XP cost) | ✅ | ✅ |
| Approve reward claims | ✅ | ✅ |
| Give bonus points (+10/+25/+50) | ✅ | ✅ |
| Approve / decline game purchases (with refund) | ✅ | ✅ |
| **Recurring rewards** (auto‑repeating) | — | ✅ |
| **Weekend‑challenge rewards** | — | ✅ |

**Free Trial mode:** create custom rewards, approve claims and game purchases,
and give bonus points throughout the trial.

**Subscription mode:** adds **recurring rewards** and **weekend‑challenge
rewards** for richer, automated motivation.
