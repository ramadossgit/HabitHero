# Parent · Progress

Track how each child is doing over time — completion rates, streaks and habit
performance.

## On the Progress section
- **At‑a‑glance tiles:** Completion rate, Day streak, Active habits, Current
  level.
- **View Reports** — opens the full Progress Reports page.

## Progress Reports page
- **Timeframe selector:** This Week · This Month · All Time.
- **Summary stats:** Total XP, current level, best streak, active habits.
- **Weekly XP chart** — a bar chart of XP earned per day.
- **Habit performance** — per‑habit completions, streaks and XP earned, with a
  weekly completion bar.

## Availability by mode

| Capability | Free Trial | Subscription |
|---|---|---|
| Completion rate, streaks, level tiles | ✅ | ✅ |
| Weekly XP chart & habit performance | ✅ | ✅ |
| **Advanced insights & analytics** (deeper trends over time) | Preview during trial | ✅ Full |

**Free Trial mode:** see the core progress view — completion rate, streaks and
weekly performance — for every child.

**Subscription mode:** unlocks the **advanced progress insights & analytics**
(part of the premium feature set) for longer‑term trend tracking.
