# Parent · Habits

Create the habits your kids complete as daily "missions," assign them to
children, schedule them, and review completions. Built as a mobile drill‑down:
**List → Habit Detail → editors**, with a **Create/Edit wizard**, an **Assign**
screen, and an **Approvals** queue.

## Habits list (main screen)
- **Search** habits by name.
- **Filter tabs:** All · Active · Inactive · Unassigned.
- **Master Habits (N)** count + **Auto‑Assign All** (assigns every habit to
  every child in one tap).
- **Approvals banner** — opens the pending‑completions queue (always reachable so
  auto‑approval settings stay accessible even with nothing pending).
- **Compact habit rows:** icon, name, status (Active/Inactive), schedule, XP
  reward, and a **⋮ quick‑actions** menu.
- **+ button (FAB):** create a new habit.

### ⋮ Quick actions (per habit)
Make Active / Make Inactive · Edit · Assign · Duplicate · Delete.

## Habit detail
Hero header (icon, name, status, XP, frequency) with two sync toggles —
**Hidden from child** and **Syncs to child's daily list** — plus actions:
- **Edit Habit** · **Assign Habit** · **Reminders** · **Duplicate Habit** ·
  **Delete Habit**.

## Create / Edit wizard
Three steps, one screen each:
1. **Basic Info** — name, description, icon (badge picker), frequency (daily /
   weekly / monthly), XP reward.
2. **Settings** — color; **schedule** (start date, end date, time‑of‑day for
   daily, weekdays for weekly, day‑of‑month for monthly, and an optional
   "stop after N times" limit); **voice reminder** (premium); active toggle.
3. **Review** — confirm and save.

## Assign habit
A per‑child list with a toggle each: turning it on assigns the habit to that
child (or reactivates it); turning it off removes the assignment.

## Approvals queue
- Pick a child (chips show each child's pending count).
- Each pending completion shows the habit, XP earned and the time completed.
- **Approve** (grants XP + reward points) or **Needs Work** (send the child a
  short feedback note so they can try again).
- **Auto‑approval settings** (premium): automatically approve completions after
  a chosen time (hours/days/weeks), with stats on time saved.
