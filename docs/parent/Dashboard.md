# Parent · Dashboard

The Dashboard is the parent's home screen — the landing view after signing in.
It is designed so the most common parenting tasks can be done at a glance
without deep navigation.

## What's on the Dashboard

### Header
- **Family name / "Parent Dashboard" title.**
- **Family Code chip** — tap to copy the 6‑character code that other parents (or
  a child during login) use to join the family.
- **Family XP** — the combined XP of all children in the family.
- **Profile avatar** — opens the parent's profile (see [Settings → My Profile](./Settings.md)).
- **Utility bar** (overview only): Tutorial, Controls, Alerts, Sign Out.
- **Trial status banner** — shows the days remaining in the free trial.

### My Children strip
- Horizontal cards for each child hero (avatar, name, level, XP).
- The top scorer is marked with a crown.
- **Add Child** shortcut.
- Tapping a child opens an inline profile panel with:
  - Total XP, available reward points, habits completed today, current streak.
  - The child's **login credentials** (username + PIN), with a **Generate Login**
    button if none exist yet.
  - **View Full Profile** (jumps to the [Kids](./Kids.md) section).

### Quick family stats
A compact strip of tiles: **Completion rate, Current streak, Badges earned,
Current level, Heroes, Active habits.**

### Pending Approvals hub (act without navigating)
The dashboard surfaces everything waiting for a parent so routine sign‑offs are
one tap away:
- **Habit approvals** — a count of completed habits awaiting review, with a
  **Review** button that jumps straight to the approval queue.
- **Reward claims** — each child's pending reward redemptions, each with an
  inline **Approve** button.
- **Game Purchase Requests** — mini‑games a child wants to buy with reward
  points, with inline **Approve / Decline** (declining refunds the points).

### Bottom navigation
Every section is one tap away from the thumb zone: **Home, Kids, Habits,
Rewards, Progress, Settings.** The Habits icon shows a badge with the number of
pending approvals.

## Availability by mode

| Capability | Free Trial | Subscription |
|---|---|---|
| Full dashboard, stats & children strip | ✅ | ✅ |
| Pending approvals hub (habits, claims, purchases) | ✅ | ✅ |
| Family code & multi‑parent join | ✅ | ✅ |
| Trial‑status banner / days remaining | ✅ (counts down) | — (shows active plan) |
| Access after the trial ends | ❌ — dashboard is gated until you subscribe | ✅ |

**Free Trial mode:** the entire dashboard is available for 7 days so you can set
up your family and see the full experience.

**Subscription mode:** the dashboard stays available and the trial banner is
replaced by your active plan status.

**After expiry:** the dashboard is replaced by a "subscribe to continue" screen;
your family data is preserved and returns when a plan is active.
