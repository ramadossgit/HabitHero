# Parent · Settings

Settings is a clean action‑row list covering account, safety and preferences. It
also hosts the **Subscription** card at the top.

Rows: **Parent Controls · Alerts & Reminders · Tutorial · My Profile · Sign Out.**

---

## Subscription (top of Settings)
- Shows the current plan or trial status and days remaining.
- **Upgrade / Manage** — choose a plan (Monthly $4.99 · Quarterly $12.99 · Yearly
  $49.99) or manage an existing subscription.

---

## Parent Controls
Per‑child safety and screen‑time management. Select a child, then adjust:
- **Daily screen‑time limit**, bonus time per completed habit, weekend bonus,
  and max game time per day.
- **Bedtime** window.
- **Feature toggles** — enable/disable Daily Habits, Gear Shop, Mini‑Games and
  Rewards for that child (a disabled feature is hidden in the child's app).
- **Emergency mode / Block all apps** — instantly restrict the child's access;
  while active, the child cannot log in and sees a clear message.

## Alerts & Reminders
Notification preferences for habit reminders:
- Enable/disable reminders and set the default **reminder lead time**.
- Choose a **ringtone**; premium accounts get the full ringtone library.
- **Voice reminders** (premium) — attach a recorded voice message.
- Can be set globally (defaults for all new habits) or per‑habit.

## Tutorial
Replays the guided onboarding walkthrough at any time.

## My Profile
- Edit first/last name, email and phone number.
- View the family code.
- Sign out.

---

## Availability by mode

| Capability | Free Trial | Subscription |
|---|---|---|
| Parent Controls (screen time, bedtime, feature toggles, emergency mode) | ✅ | ✅ |
| Alerts & Reminders — basic reminders + free ringtones | ✅ | ✅ |
| Alerts & Reminders — **voice reminders** | ✅ Try during trial | ✅ |
| Alerts & Reminders — **premium ringtone library** | — | ✅ |
| Tutorial | ✅ | ✅ |
| My Profile | ✅ | ✅ |
| Subscription card — upgrade / manage plan | ✅ (upgrade) | ✅ (manage) |

**Free Trial mode:** all safety controls and preferences are available; premium
reminder extras (voice messages) can be tried during the trial.

**Subscription mode:** keeps everything and adds the full premium ringtone
library; the Subscription card manages your active plan instead of counting down
a trial.
