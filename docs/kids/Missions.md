# Kids · Missions

Missions is the child's home tab — where daily habits become hero quests. Kids
log in with **Family Code + Username + PIN** (no email needed).

## What's on the Missions tab
- **Hero header** — the child's avatar, name, level and an XP progress bar toward
  the next level.
- **Habit Health meter** — a fun daily health score showing how many of today's
  missions are done (e.g. 3/5 and a percentage), with a colored progress bar.
- **Today's Missions** — only the habits scheduled for today appear as cards,
  each showing the habit name, its XP reward, and availability.

## Completing a mission
- Tap **Complete!** on a mission.
- The completion is submitted for the parent to review; the card shows **Pending
  / Waiting for parent**.
- When the parent **approves**, the child receives the habit's **XP** (levels up
  the hero) and **reward points** (spendable in Rewards, Customize and Games).
- If the parent sends it back (**Needs Work**), the card shows their message and
  the child can **Try Again**.
- If the parent has enabled **auto‑approval** (premium), completions are approved
  automatically after the set time.

## Availability by mode

| Capability | Free Trial | Subscription |
|---|---|---|
| See & complete today's missions | ✅ | ✅ |
| Earn XP, level up, earn reward points | ✅ | ✅ |
| Habit Health meter & streaks | ✅ | ✅ |
| Number of habits available | Basic set during trial | ✅ Unlimited |
| Faster approvals via parent **auto‑approval** | ✅ if parent enables (trial) | ✅ |

**Free Trial mode:** kids can complete missions and earn XP/points normally
during the 7‑day trial.

**Subscription mode:** unlimited habits & levels, plus streak bonuses and
achievements, so the mission experience keeps growing.
