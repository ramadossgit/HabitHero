# Kids · Games

The Games tab (Game Zone) is where kids spend reward points to buy and play
age‑appropriate mini‑games — a fun payoff for completing their habits.

## Game Zone
- **My points / My games** — the child's point balance and how many games they
  own.
- **Category filters** — All Games, by age group (Ages 3‑5 / 6‑8 / 9‑12),
  Puzzles, Wellness, etc.
- **Game cards** — each shows the game, its age group, best score and play count.
- Only games appropriate for the child's **age** (set by the parent) are shown.

## Buying & playing
- **Buy** — request a game with reward points; the purchase goes to the parent
  for approval. On approval the game unlocks (declining refunds the points).
- **Play** — launch an owned game; games run smoothly on phones, tablets and web
  (drag‑and‑drop, tap, timed rounds, etc.).
- **Levels** — many games have multiple levels the child can unlock with points;
  each level has its own timer and scales in difficulty. Completing rounds earns
  XP.

The Game Zone respects the parent's **Mini‑Games** feature toggle in
[Parent Controls](../parent/Settings.md) and the per‑day game‑time limit.

## Included mini‑games (examples)
Shape Match, Color Pop Balloons, Animal Sound Quiz, Emotion Faces, Memory Flip,
and more across puzzle, learning and wellness categories.

## Availability by mode

| Capability | Free Trial | Subscription |
|---|---|---|
| Game Zone browsing | ✅ | ✅ |
| **Balloon Pop** mini‑game | ✅ Included in trial | ✅ |
| Buy games with reward points (parent‑approved) | ✅ | ✅ |
| **Full mini‑game catalog unlocked** | Limited during trial | ✅ All games |
| Level unlocks & scores | ✅ | ✅ |

**Free Trial mode:** the Game Zone is available and includes the Balloon Pop
mini‑game so kids can experience games during the trial.

**Subscription mode:** **all mini‑games are unlocked**, giving access to the full
catalog across every age group and category.
