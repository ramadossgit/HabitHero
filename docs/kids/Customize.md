# Kids · Customize

The Customize tab lets a child personalize their hero using the **reward points**
they earn from completing missions. It contains two shops: the **Avatar Shop**
and the **Gear Shop**.

## Avatar Shop
- Browse hero avatars (Robot, Princess, Ninja, Animal and more).
- **Unlock** new avatars by spending reward points.
- **Equip** any unlocked avatar to change how the hero looks across the app.
- The child starts with a default avatar already unlocked.

## Gear Shop
- Browse gear and costume items for the hero.
- **Unlock** items with reward points and equip them to customize the hero's
  look.

Both shops respect the parent's **Gear Shop** feature toggle in
[Parent Controls](../parent/Settings.md) — if a parent disables it, the child
sees a friendly "ask your parent" message instead.

## Availability by mode

| Capability | Free Trial | Subscription |
|---|---|---|
| Avatar Builder / basic avatars | ✅ | ✅ |
| Gear Shop (basic items) | ✅ | ✅ |
| Spend earned reward points to unlock & equip | ✅ | ✅ |
| **Exclusive avatars & costumes** | Preview during trial | ✅ Fully unlocked |

**Free Trial mode:** the Avatar Builder and basic customization are available so
kids can style their hero during the trial.

**Subscription mode:** unlocks the **exclusive avatars & costumes** catalog
(part of the premium feature set) for the full customization experience.
